# Python Crime Data Analysis

A Python data analysis project focused on exploring crime patterns, identifying trends, and extracting meaningful insights from crime-related data.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly

## Project Objective

The objective of this project is to explore crime data, analyze patterns and trends, and use data visualization to better understand crime characteristics.

## Key Analysis

* Analyzed crime occurrences by time of day.
* Identified areas with higher numbers of reported crimes.
* Examined the distribution of victim ages.
* Analyzed crime patterns by gender.
* Identified the most frequently reported crime types.
* Explored relationships and patterns within the dataset.

## Key Insights

* Examined the distribution of crime occurrences across different hours.
* Identified periods with higher crime activity.
* Analyzed the areas with the highest number of reported crimes.
* Explored victim age groups and gender distribution.
* Identified frequently occurring crime categories.
